# Go2Havasu

Website source for **go2havasu.com** — Lake Havasu, Arizona visitor information and lifestyle merchandise.

## Current build

- Responsive homepage
- Lake Havasu discovery and trip-planning sections
- Merchandise concepts for hats, T-shirts, and mugs
- Demo cart interaction
- Newsletter signup placeholder
- Custom-domain file for `go2havasu.com`
- Static-site configuration for GitHub Pages
- Official Go2Havasu logo integrated into the site

## Files

- `index.html` — homepage
- `styles.css` — responsive styling
- `script.js` — mobile menu, demo cart, and signup interactions
- `CNAME` — custom domain
- `.nojekyll` — static GitHub Pages support
